### 1. LLM fundamentals
- LLM behavior and next-token prediction; tokens, context and latency
- Images, audio and PDFs; output controls; model limitations and failure modes; choosing a model

### 2. Building with LLM APIs
- LangChain basics, conversations and prompt templates; open and local models; streaming
- Structured outputs and validation; tool calling; chains and routing
- Failure handling, retries and fallbacks; batch and concurrent processing; cost, logging and tracing

### 3. Prompt engineering
- Prompt anatomy; zero-shot and few-shot prompting; system prompts and output control
- Reasoning and task decomposition; prompt testing and improvement; automatic prompt improvement
- Prompt versioning, cost and caching; prompt injection basics

### 4. Retrieval-augmented generation (RAG)
- When to use RAG; document loading, cleaning and parsing; chunking
- Embeddings, semantic search and vector databases; building a RAG pipeline; citations and uncertainty
- Keyword and hybrid search; smarter chunks and filters; reranking; query transformation
- Routing and adaptive RAG; self-correcting RAG; structured-data RAG; graph RAG and pattern selection
- Failure analysis; test sets and scoring; retrieval and answer evaluation; regression tests
- RAG threats, hidden instructions and poisoned documents; access control; personal data and secrets; red-teaming

### 5. AI agents
- Agent concepts and loops; LangGraph; agent tools; planning and reflection
- Saving progress and approval; MCP fundamentals and MCP servers; memory
- Context engineering, compaction, offloading and tool context; harness engineering
- Multi-agent patterns and systems; reliability and user experience
- Agent evaluation, tool use, task success, recovery, memory and efficiency
- Threats and least privilege; approval gates, sandboxing, MCP and tool security; red-teaming

### 6. Shipping to production
- AI system design; turning a prototype into a service; building a frontend
- Packaging and deployment; automated checks and safe releases; production monitoring
- Cost, speed and scale; model gateways and managed platforms; serving open models
- When to fine-tune; LoRA; evaluating, serving and distilling fine-tuned models
- Incident handling and whole-app security review
